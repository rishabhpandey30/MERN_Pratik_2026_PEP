**SONARQUBE**
------------------------------------------------------------
Q.WHAT IS SONARQUBE?

SonarQube is a code quality and security analysis tool that scans your source code to detect bugs, vulnerabilities, and maintainability issues.

In Simple term:-
SonarQube = Code Quality Checker 🔍

It helps developers understand:
What is wrong
Where it is wrong
How to fix it

Q.WHAT DOES SONARQUBE DO?

SonarQube analyzes your code and identifies:

-  Bugs → Logical or runtime errors
- Security Vulnerabilities → Risks like SQL injection, XSS
- Code Smells → Poor coding practices
- Duplicate Code → Repeated blocks of code
- Complexity Issues → Hard-to-maintain logic

Key Features:
Quality Gates → Pass/Fail criteria for code quality
Code Coverage → Measures test coverage
Static Code Analysis → No need to run code
Integrates with tools like:
Jenkins
GitHub
GitLab
------------------------------------------------------------
WHAT IS STATIC ANALYSIS?
------------------------------------------------------------
Static analysis is the process of analyzing source code without executing it to detect potential issues early in the development cycle.

In simple terms:
Static Analysis = Checking code without running it 🔍

What it Detects:
- Bugs (logical mistakes)
- Security vulnerabilities
- Code smells (bad practices)
- Code complexity issues
- Duplicate code

How It Works (Flow):
1. Developer writes code
2. Code pushed to Git
3. CI/CD pipeline runs
4. SonarQube scans the code
5. Generates a detailed report

Q. What is Quality Gate?
A Quality Gate in SonarQube is a set of conditions that determines whether code is fit for deployment based on quality and security metrics.

Quality Gate = Exam Pass Criteria 

Fail → Not promoted
Pass → Move forward
